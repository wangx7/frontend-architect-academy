# 03 实验：亲手验证沙盒（14 个零依赖实验室）

> **“看懂的错觉”和“真正的架构功底”之间，隔着一次亲手运行。**
>
> 本实验室收录了与【01-教程】和【02-概念】一一对应的 **14 个极简可运行实验**：
> - **零安装成本**：全部采用 Node.js 标准库（直接 `node xxx.mjs` 运行）或浏览器 DevTools Console；
> - **破坏性验证**：每个实验不仅带你跑通正常结果，还会让你亲手改一个参数，把栈撑爆、把页面卡死、把库存超卖、把集群分区，亲眼看见故障是怎么诞生的；
> - **独立思考与折叠详解**：每个实验末尾均配有推导思考题与 `<details>` 折叠式参考答案。
