# 02 概念：零黑话具象图解词典（20 篇）

> **为什么单独设立《02 概念》？**
>
> 很多同学在看技术文档时半途而废，都是因为作者在讲一个新东西时，随手甩出 `双向链表`、`哈希冲突`、`红黑树`、`B+ 树`、`最长递增子序列`、`MVCC` 等名词却不解释具体长相。
>
> 在这里，**每一个概念词条都严守“零超纲黑话”铁律**：
> 1. 先讲清楚**它被什么痛点逼出来的**；
> 2. 用**带门牌号（`#100`, `#101`）的内存格子**画出它**从 0 到 1 的生长慢放图**；
> 3. 给出 **15～25 行纯 JS 最小实现**；
> 4. 对照列出它在**前端架构**与**后端架构**中的真实用武之地。
