# 02 概念｜零黑话具象图解词典（20 篇）

> **阅读铁律**：这里没有任何故作高深的学术黑话，也**绝不用你还没学过的专业词去解释另一个新词**。  
> 每一篇概念都是从 `#100` 号内存格子和真实业务痛点出发，用**连续帧字符画**带你亲眼看着数据结构和底层协议从 0 到 1 长出来。你可以在阅读 [01-教程](../01-教程/index.md) 遇到生词时随时跳过来查阅，也可以顺着下面的进化链条从第 01 篇一口气通关！

| 序号 | 概念篇章 | 它解决了上一棒留下的什么死穴？ | 前后端落地核心场景 |

| **02** | [数组与连号房间](./02-数组与连号房间.md) | 把房间连号排列，靠 `起点 + 下标` 实现 `O(1)` 1 步算术直达 | TypedArray 像素缓冲、虚拟列表切片、V8 快慢数组降级陷阱 |
| **03** | [单向链表与双向链表](./03-单向链表与双向链表.md) | 治好数组往中间插人要“全员搬家（`O(n)`）”的灾难，改 2 张纸条即可插删 | React Fiber 链表树、Vue 3.4 响应式依赖链、Linux 内核就绪队列 |

| **07** | [2-3 树与红黑树](./07-2-3树与红黑树.md) | 治好 AVL 树旋转过于频繁的洁癖，用“满 3 拆房 + 红胶水室友”统治内存检索 | Linux `epoll` 十万并发连接树、CFS 进程调度器、Java `HashMap` 红黑树 |
| **08** | [B 树与 B+ 树](./08-B树与B+树.md) | 适配硬盘 16KB 整页批发特性，用“脱水目录页 + 底部双向链表”3 层管两千万行 | MySQL InnoDB 聚簇索引/回表/覆盖索引、IndexedDB、游标分页与自增主键铁律 |
| **09** | [LRU 缓存淘汰算法](./09-LRU缓存淘汰算法.md) | 让“哈希表指路”与“双向链表排队”强强联手，实现查询、提鲜、淘汰全 `O(1)` | Vue 3 `<KeepAlive>` 组件缓存、前端大图纹理池、Redis 与 MySQL 缓冲池 |
| **10** | [最长递增子序列 LIS](./10-最长递增子序列LIS.md) | 用“潜力替补槽位 + 前驱纸条回溯”，找出乱序 DOM 中无需移动的最大稳定队伍 | Vue 3 `patchKeyedChildren` 快速 Diff 算法核心、`git diff` 行比对 |
