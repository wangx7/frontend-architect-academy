# 概念 04｜栈与队列（Stack & Queue）

> **一句话人话定义**：栈和队列不是新的物理存储结构，而是给[数组](./02-数组与连号房间.md)或[链表](./03-单向链表与双向链表.md)立下的两条**“进出家规”**——**栈（Stack）是餐厅洗碗叠盘子（后进先出 LIFO）**，**队列（Queue）是奶茶店排队点单（先进先出 FIFO）**。

## 1. 它们被什么痛点逼出来的？

如果允许程序里的任务或状态随便插队、随便乱取，两件事会立刻失控：
1. **函数调用与回退会乱套**：`A()` 调用了 `B()`，`B()` 又调用了 `C()`。显然必须等最里层的 `C()` 先跑完返回，才能接着跑 `B()`，最后回到 `A()`——这需要**“最后进去的人最先出来”**的规矩（**栈**）。
2. **异步事件与请求处理会不公平**：用户先点了“加入购物车”，后点了“去结算”，或者同一秒涌进 1,000 个排队请求——这需要**“先来的人先服务”**的规矩（**队列**）。

## 2. 内存格子动态图解

```text
【栈 Stack：单口死胡同 / 叠盘子（后进先出 LIFO）】
   压入 push(3) ──►  ┌─────────┐  ──► 弹出 pop() 先拿走 3！
                     │ 盘子 3  │  ◄── 栈顶 (Top)
                     ├─────────┤
                     │ 盘子 2  │
                     ├─────────┤
                     │ 盘子 1  │  ◄── 栈底 (Bottom，最先放进去，最后才能拿走)
                     └─────────┘

【队列 Queue：双口通道 / 排队过安检（先进先出 FIFO）】
   队尾入列 enqueue(3) ──► [ 顾客3 | 顾客2 | 顾客1 ] ──► 队头出列 dequeue() 先服务顾客1！
```

## 3. 20 行极简代码原型：用栈匹配 HTML 闭合标签 & 用队列调度任务

```js
// 1. 栈的经典应用：浏览器 HTML 解析器如何检查标签是否正确闭合？
function isValidHTML(tags) {
  const stack = []
  for (const tag of tags) {
    if (!tag.startsWith('/')) {
      stack.push(tag)          // 遇到开始标签 <div>、<p>：压入栈顶
    } else {
      const top = stack.pop()  // 遇到结束标签 </p>：弹出栈顶核对是否配对！
      if ('/' + top !== tag) return false
    }
  }
  return stack.length === 0
}
console.log('HTML 标签合法?', isValidHTML(['div', 'p', '/p', '/div'])) // true

// 2. 队列的经典应用：按先后顺序依次清空排队任务
const taskQueue = ['任务1: 发请求', '任务2: 更新DOM', '任务3: 打埋点']
while (taskQueue.length > 0) {
  const current = taskQueue.shift() // 永远从队头取出最先排队的任务
  console.log('正在执行 ->', current)
}
```

## 4. 前后端架构双视角落地

| 结构 | 前端架构中的核心应用 | 后端与系统架构中的核心应用 |
| :--- | :--- | :--- |
| **栈 (Stack)** | 1. **JS 函数调用栈（Call Stack）**（无限递归把栈塞满即报 `Maximum call stack size exceeded`）；<br>2. **Vue 3 `effectStack`**（解决组件嵌套渲染时当前激活 effect 的恢复）；<br>3. **浏览器 History 前进后退栈**、富文本编辑器 `Undo/Redo` 撤销重做双栈；<br>4. **树与图的深度优先遍历（DFS）** | 操作系统线程调用栈、编译器语法解析（AST 构建）、JVM 操作数栈 |
| **队列 (Queue)** | 1. **浏览器事件循环（宏任务队列与微任务队列）**；<br>2. **Vue 3 `Scheduler` 异步更新队列**；<br>3. **前端大文件分片上传并发控制池**；<br>4. **树与图的广度优先遍历（BFS）** | **消息队列（Kafka / RabbitMQ）** 异步削峰、网关请求缓冲队列、数据库连接池等待队列、操作系统进程调度队列 |
