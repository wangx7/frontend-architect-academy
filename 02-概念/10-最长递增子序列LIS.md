# 概念 10｜最长递增子序列 LIS（Longest Increasing Subsequence）

> **一句话人话定义**：当一排已经存在于页面上的 DOM 节点顺序被打乱时，为了**少搬动真实 DOM**，先挑出其中**“相对先后顺序本来就没乱”的最长一串节点让它们原地坐着不动**，只去搬动剩下的少数几个捣乱节点——找出这串“原地不动最大队伍”的算法，就叫 **最长递增子序列（LIS）**！

## 1. 它被什么痛点逼出来的？

在浏览器里，修改一个 JS 对象属性只需几纳秒，但调用 `insertBefore` **移动一个真实 DOM 节点**却很贵。
假设旧列表是 `[C, D, E]`（它们在旧列表里的位置编号分别是 `2, 3, 4`），更新后新列表变成了 `[E, C, D, H]`：
- 新列表这四项在旧列表里的老位置编号分别是：**`[ 4, 2, 3, 0 ]`**（其中 `H` 是全新节点，记为 `0`）。
- **笨办法**：把 `E, C, D` 三个真实 DOM 全部拆下来重新插一遍（移动 3 次）。
- **聪明办法（Vue 3 快速 Diff）**：仔细盯着 `[ 4, 2, 3 ]` 看！里面的 **`2 (C)` 和 `3 (D)` 从小到大递增，说明 `C` 在 `D` 前面这个先后顺序在更新前后根本没变！**
  既然 `C` 和 `D` 的先后顺序本来就是对的，那我们就**让 `C` 和 `D` 稳坐原地一动不动**，只需要把 `E(4)` 拎到 `C` 前面（**只移动 1 次！**），再把新节点 `H(0)` 挂上去就完事了！

## 2. 从 0 到 1 慢放图：Vue 3 `getSequence` 是怎么用“贪心 + 前驱纸条”算出来的？

给定一串老位置编号（比如 `arr = [ 2, 5, 3, 7, 11, 8 ]`），怎么快速找出最长递增子序列？
如果暴力枚举所有组合要 $O(2^n)$，太慢了。Vue 3 用了一个极其巧妙的 **“潜力替补法（贪心 + 二分查找 + 前驱门牌号纸条）”**：

### 核心心法：同样的队伍长度，排尾的数字越小，后面越容易接上更多数字！
1. 先放 `2`：队伍是 `[2]`；
2. 来 `5`（比 2 大）：直接接在后面，队伍变成 `[2, 5]`（`5` 手里拿一张前驱纸条写着：“我前面是 `2`”）；
3. 来 `3`（比 5 小，比 2 大）：虽然 `3` 不能接在 `5` 后面把队伍变长，但**作为第 2 号位选手，`3` 比 `5` 更年轻、更有潜力（因为后面来 `4` 的话能接在 `3` 后面，却接不在 `5` 后面）！** 于是用二分查找找到第一个比 `3` 大的 `5`，把槽位替补成 `[2, 3]`（`3` 手里拿前驱纸条写着：“我前面是 `2`”）；
4. 来 `7`、`11`：依次接在后面，队伍变成 `[2, 3, 7, 11]`（每次接上去的人都拿一张纸条记住自己前面是谁）；
5. 来 `8`：替补掉 `11`，槽位变成 `[2, 3, 7, 8]`；
6. **最后一步（顺着纸条倒着点名）**：从队伍最后一个人出发，顺着每个人手里的“前驱纸条”一路往回找，就还原出了百分百真实的递增子序列（注意 Vue 3 返回的是这些数字所在的**数组下标**）！

```text
输入数组 arr   :  [  4,    2,    3,    0  ]   （对应新列表里的 [E, C, D, H]，0 代表新节点跳过）
数组下标 idx   :     0     1     2     3

第 1 步 (idx=0, 值=4) : 队伍存下标 [0] (对应值 [4])
第 2 步 (idx=1, 值=2) : 2 比 4 更有潜力！替换掉 0，队伍存下标 [1] (对应值 [2])
第 3 步 (idx=2, 值=3) : 3 比 2 大！直接追加，且记下前驱纸条 p[2] = 1，队伍存下标 [1, 2] (对应值 [2, 3])
第 4 步 (idx=3, 值=0) : 0 是全新节点，跳过！

最终返回无需移动的下标 : [ 1, 2 ] ──► 即新列表下标 1(C) 和下标 2(D) 原地不动！
```

## 3. 30 行极简代码原型：Vue 3 `renderer.ts` 源码同款 `getSequence`

```js
// 100% 还原 Vue 3 源码中的 getSequence（返回最长递增子序列的【数组下标】）
function getSequence(arr) {
  const p = arr.slice()                 // 存放每个元素的前驱下标纸条
  const result = [0]                    // 存放递增子序列的数组下标
  for (let i = 0; i < arr.length; i++) {
    const val = arr[i]
    if (val === 0) continue             // 0 代表全新节点，不参与旧节点复用排队
    const lastIdx = result[result.length - 1]
    if (arr[lastIdx] < val) {           // 比队尾还大：直接排到队尾，并记下前任是谁
      p[i] = lastIdx
      result.push(i)
      continue
    }
    // 否则二分查找第一个比 val 大的位置，用更有潜力的 val 替补上去
    let u = 0, v = result.length - 1
    while (u < v) {
      const c = (u + v) >> 1
      if (arr[result[c]] < val) u = c + 1
      else v = c
    }
    if (val < arr[result[u]]) {
      if (u > 0) p[i] = result[u - 1]
      result[u] = i
    }
  }
  // 从队尾顺着前驱纸条 p 一路倒推回溯，确保顺序完全正确
  let len = result.length, cur = result[len - 1]
  while (len-- > 0) { result[len] = cur; cur = p[cur] }
  return result
}

console.log('[4, 2, 3, 0] 中无需移动的下标:', getSequence([4, 2, 3, 0])) // [1, 2]
```
