# 概念 03｜单向链表与双向链表（Linked List）

> **一句话人话定义**：链表就是**废除“连号坐”规矩**，大家散住在内存各处的空房间里，靠每个人手里攥着**“前任（`prev`）和后任（`next`）的门牌号纸条”**排成一队——插队和退队只需改两张纸条（$O(1)$），谁都不用搬家！

## 1. 它被什么痛点逼出来的？

在 [概念 02：数组](./02-数组与连号房间.md) 里我们看到，数组为了保住“连号房间”，每次往中间插一个元素，后面成千上万个元素都得集体往后搬家。
怎么才能让插入和删除新元素时，**旧元素在原地一动不动**？
答案就是：**别挨着住了！用门牌号纸条单线联系！**

## 2. 内存门牌号从 0 到 1 慢放图

### 2.1 单向链表（Singly Linked List）：只攥着“下一个人”的纸条
我们要按顺序存 `["起床", "刷牙", "吃早饭"]`，它们散住在 `#105`、`#620`、`#312` 三个不挨着的房间里：

```text
链表头 head = #105

#105 { task: "起床",   next: #620 }  ──(看纸条去 #620)──►
#620 { task: "刷牙",   next: #312 }  ──(看纸条去 #312)──►
#312 { task: "吃早饭", next: null }  （null 代表队尾没人了）
```

现在要在 `#105`（起床）和 `#620`（刷牙）中间插一个 `#888`（穿衣服），只需改 **2 张纸条**：
1. 让新来的 `#888` 的 `next` 纸条写上 `#620`；
2. 把 `#105` 的 `next` 纸条从 `#620` 改成 `#888`。

```text
#105 ("起床", next: #888) ──► #888 ("穿衣服", next: #620) ──► #620 ("刷牙", next: #312)
```
看！`#620` 和 `#312` 连屁股都没抬一下！

### 2.2 为什么单向链表还不够用，非要进化出“双向链表”？
单向链表有一个极其尴尬的死角：**“认识后任，不认识前任”**。
假设你手里已经拿到了节点 `#620`（刷牙），现在你想**把 `#620` 从链表里删掉**（或者像缓存一样把 `#620` 拎到队伍最前面）。
要把 `#620` 摘掉，必须让它的**前任（`#105`）**把 `next` 纸条改成 `#312`。可 `#620` 手里只有指向 `#312` 的 `next` 纸条，根本不知道自己的前任住在 `#105`！你只能被迫从排头 `head` 开始挨个跑腿找谁指向了 `#620`。

解法极其干脆：**左手多拿一张 `prev` 纸条记前任门牌号，右手拿 `next` 纸条记后任门牌号！** 这就是 **双向链表（Doubly Linked List）**：

```text
#105 { prev: null,  task: "起床",   next: #620 }
        ▲                                  │
        └──────────────┬───────────────────┘
                       ▼
#620 { prev: #105,  task: "刷牙",   next: #312 }
        ▲                                  │
        └──────────────┬───────────────────┘
                       ▼
#312 { prev: #620,  task: "吃早饭", next: null }
```

现在，只要给你任何一个节点 `node`（比如 `#620`），只需两行代码就能在 $O(1)$ 时间内把它从队伍里原地摘除：
- `node.prev.next = node.next`（让我的前任 `#105`，右手直接拉住我的后任 `#312`）
- `node.next.prev = node.prev`（让我的后任 `#312`，左手直接拉住我的前任 `#105`）

### 2.3 链表的致命软肋是什么？
虽然插队改纸条只需 1 步，但因为房间门牌号不连续，**你想找排在第 500 位的元素，或者按名字找某个元素，没有任何算术公式可用，只能从头节点挨个看纸条跑 500 趟腿（查询是 $O(n)$）！**
怎么才能既有数组的 1 步直达，又有链表的不搬家？这直接逼出了 **[概念 05：哈希表与冲突拉链](./05-哈希表与冲突拉链.md)**！

## 3. 20 行极简代码原型：双向链表节点的原地插入与秒删

```js
// 双向链表核心操作：已知节点时，插入和删除永远只需改几张纸条 O(1)
const head = { name: '起床', prev: null, next: null }
const tail = { name: '吃早饭', prev: head, next: null }
head.next = tail

// 1. 在 head 和 tail 之间插入 mid ("刷牙")
const mid = { name: '刷牙', prev: head, next: tail }
head.next = mid
tail.prev = mid
console.log('插入后:', head.name, '->', head.next.name, '->', head.next.next.name)

// 2. 只凭 mid 节点自己，1 步把自己从队伍里摘除（无需从头遍历！）
mid.prev.next = mid.next
mid.next.prev = mid.prev
console.log('摘除 mid 后:', head.name, '->', head.next.name)
```
